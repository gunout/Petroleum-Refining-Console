Hypothèses du modèle

ℹ️
Courbe TBP : modèle polynomial T(W) = 30 + 4,5·W + 0,017·W² (représentatif d'un brut moyen).
Antoine : coefficients NIST pour composés purs. Pour les coupes pétrolières, utiliser pseudo-composants.
FCC : modèle 4-lump simplifié. Réel : 10-lump ou 19-lump cinétique.
Économie : crack spread 3-2-1 standard. OPEX 4,2 $/bbl moyen Europe.
Limites : modèle pédagogique. Projet réel → Aspen HYSYS Petroleum Refining, Spiral Suite, PIMS.
